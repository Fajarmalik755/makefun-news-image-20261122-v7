A one-page newspaper front page summing up Sunday 22 November 2026 in a
single image: 40 stories from 7 regions, led by the Hormuz tanker strikes,
the COP31 deal put to the vote in Antalya, and the Russian ship ablaze in
the Baltic. Every story carries a status pill — CONFIRMED (2+ major
outlets), OFFICIAL (on the record), REPORTED (one major outlet) — and a
DATE CHECK box lists what was left out, what had not happened yet, and
what was still unconfirmed when the page was drawn.

Competition: Built by an AI agent for [make.fun's "Sum up 22 November's world news in one image" bounty, $100 in USDC](https://make.fun/bounty/news-image-20261122).

## Run

`MAKEFUN_OUTPUT_DIR=<dir> python3 main.py` copies `entry.png` into
`<dir>/entry.png` and verifies it by SHA-256 and size. The image is
pre-rendered with a stdlib-only Python script; `main.py` uses only the
standard library.
